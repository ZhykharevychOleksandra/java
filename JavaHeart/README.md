# Java Heart Animation 

A standalone desktop application featuring physics-based particle animation that dynamically forms a beating heart shape.

### Technologies
* Java Core
* Java Swing (Graphics2D)

### Features
* Mathematical particle rendering.
* Physics-based animation vectors.
* UI state and frame management.
